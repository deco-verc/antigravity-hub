# Minimalist SaaS & Editorial Design System

## 1. Palette & Surfaces
- **Canvas:** `#0a0a0a` (Dark) / `#ffffff` (Light)
- **Surface 1:** `#121212` / `#f7f7f8`
- **Surface 2:** `#1a1a1a` / `#efeff0`
- **Hairline Border:** `rgba(255, 255, 255, 0.08)` / `rgba(0, 0, 0, 0.08)`
- **Text Ink:** `#f5f5f5` / `#111111`
- **Text Muted:** `#a1a1aa` / `#71717a`
- **Accent:** Single monochromatic or subdued neutral tint.

## 2. Typography
- **Headings:** Clean sans-serif (Inter, Geist, SF Pro) with `-0.02em` letter-spacing.
- **Numbers/Metrics:** `font-variant-numeric: tabular-nums` mandatory.
- **Rhythm:** Generous vertical padding (`py-12`, `py-16`) and content-driven line height.

## 3. Interaction
- **Dials:** `VARIANCE: 5 | MOTION: 3 | DENSITY: 3`
- **Transitions:** Subdued opacity and subtle 1px transforms on hover.
